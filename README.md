# salary-management-system

**ACME Salary Management System**: a full-stack HR application (FastAPI, React, PostgreSQL) for managing employees, salaries, salary history and compensation analytics across INR / USD / EUR.

The project lives in [`acme-salary-management/`](acme-salary-management). Start with its **[README](acme-salary-management/README.md)** for setup, configuration, tests and deployment, and [`acme-salary-management/docs/`](acme-salary-management/docs) for design notes and the deployment checklist.

```
acme-salary-management/
├── backend/    FastAPI + SQLAlchemy + Alembic + seed script
├── frontend/   React + TypeScript + Vite
└── docs/       requirements, architecture, database design, decisions, plan, deployment checklist
```
